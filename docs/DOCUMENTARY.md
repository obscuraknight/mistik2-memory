# Mistik2 Memory Documentary

The project documentary is distributed with the full public-release bundle as:

`media/mistik2-memory-documentary.mp4`

For GitHub, the recommended publication path is a **Release asset**, not a tracked Git blob. This keeps normal clones small and avoids permanently adding an 88 MB binary to repository history.

The documentary introduces the wider Mistik project and the governed-memory philosophy. It is supplementary media, not normative technical documentation. The README, architecture, security, durability, API and validation documents define the actual software contract.

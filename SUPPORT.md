# Support

Mistik2 Memory is an open-source developer library maintained on a best-effort basis.

## Bugs

Use GitHub Issues for reproducible bugs that do not contain sensitive information. Include the package version, Python version, operating system/filesystem, minimal synthetic reproduction, and observed/expected behavior.

## Security

Do not file exploitable security or privacy issues publicly. Follow `SECURITY.md` and use GitHub private vulnerability reporting when available.

## Integration questions

For usage questions, first check `README.md`, `docs/DEVELOPER_GUIDE.md`, `docs/API_REFERENCE.md`, `DURABILITY.md`, and `UPGRADING.md`.

## Production responsibility

The host application remains responsible for authentication, authorization, tenant isolation, quotas, backups, secret management, and safe model-tool permissions.
